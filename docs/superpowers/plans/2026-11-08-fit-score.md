# Fit score Implementation Plan

Status: implemented and locally verified on 8 Nov 2026. The signed commit,
coordinator push, pull request, and exact-head GitHub CI remain pending.

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give qualified Discovery leads an explainable 0 to 100 outreach fit score, prevent an explicitly filtered batch from including unsuitable leads, and show a reasoned Not contacted list.

**Architecture:** A pure desktop module reads the existing Maps snapshot and qualification observation head. It returns either a score with named contributions or an unscored result when qualification is absent or incomplete. The existing batch planner consumes that exact result, while Leads and lead detail render it without creating a relay record or page.

**Tech Stack:** TypeScript, React 19, existing desktop mock bridge, Node test runner, Playwright.
